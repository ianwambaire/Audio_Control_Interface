# Audio Control Interface Lab

## Project Overview
This project is a custom audio control interface built using HTML, CSS, and JavaScript.  
It allows users to interact with an audio file using programmed controls instead of the default browser audio player.

The interface is designed as a one-page portfolio-style layout to make the application more interactive, organized, and easy to use.

## Live Demo
https://ianwambaire.github.io/Audio_Control_Interface/

## Features

- Play and Pause audio
- Volume control using a slider
- Mute and Unmute functionality
- Skip forward and backward (5 seconds)
- Playback speed control (1x, 1.25x, 1.5x, 2x)
- Display of current playback time and duration
- Progress bar for seeking audio
- Loop / Repeat feature
- Keyboard controls for interaction
- Custom portfolio-style user interface

## How to Use

- Click **Play** to start the audio
- Click **Pause** to stop playback
- Adjust volume using the slider
- Use **Mute** to silence the audio
- Use **-5s** and **+5s** to skip
- Click the speed button to change playback speed
- Click **Loop** to enable or disable repeat
- Use keyboard shortcuts for faster control:
  - Space = Play / Pause
  - M = Mute / Unmute
  - L = Loop On / Off
  - Arrow Left = Backward 5 seconds
  - Arrow Right = Forward 5 seconds
